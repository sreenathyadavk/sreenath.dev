AI Meeting Tracker

Record a meeting, get the transcript, pull out the tasks, and ask questions about what was said — entirely locally.

The Objective

Cloud-based meeting transcription services (like Otter.ai) require sending sensitive internal corporate audio over the internet to third parties. I built the AI Meeting Tracker to solve this: it is a 100% self-hosted, no-cloud meeting intelligence system that transcribes and analyzes meetings strictly on your own machine.

Architecture

The system is a full-stack web application. The frontend is built in Vue 3 for a reactive dashboard experience. The backend uses FastAPI and SQLAlchemy to manage data models, backed by a persistent SQLite database for fast local storage.

Local AI Orchestration

Audio is ingested and transcribed locally using OpenAI's Whisper model. Once transcribed, the backend pipes the raw text to a locally running instance of Ollama (Llama 3.1). The LLM is prompted strictly to extract structured JSON containing action items, owners, deadlines, and a confidence score for each extracted task.

Engineering Challenges

The core challenge was forcing a local LLM to consistently return valid, structured JSON schemas without hallucinating or diverging into conversational responses. I achieved this through rigid prompting techniques and backend schema validation before the data is committed to SQLite and sent to the Vue frontend.
