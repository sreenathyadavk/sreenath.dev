WHIS

A personal AI assistant I'm building from the ground up — local models, multiple agents, memory, RAG, tools, and a lot of debugging.

The Objective

WHIS (Whole Holistic Intelligent System) was designed to bridge the gap between natural language intent and low-level system execution safely and deterministically. The goal was to build a deeply integrated, autonomous Personal AI Operating System that operates natively on my machine, managing system states and executing complex multi-step workflows without relying on external cloud APIs or risking catastrophic OS mutations.

Architecture & Orchestration

The system is built on a central global router that dispatches tasks to isolated sub-agents. It uses Ollama for local LLM inference, completely severing external dependencies. WHIS routes requests through an intent and authority layer before selecting an execution path. The agents are explicitly decoupled from the router to ensure absolute stability and isolated debugging during their construction.

Specialized Agents

The System Agent handles OS navigation and execution using ReAct orchestration. It safely interfaces with the Linux environment, evaluates terminal state mutations, and executes strict commands without monopolizing resources.

The Internet Agent handles web research using a deterministic RAG (Retrieval-Augmented Generation) pipeline. It acts as a sub-8s cognitive engine that concurrently fetches, semantically chunks data via BM25, and synthesizes information from the external web while strictly resisting adversarial noise and hallucinations.

Memory & Persistence

Unlike simple conversational scripts, WHIS requires persistent state. I designed a local SQLite-backed memory engine (`whis_memory_v2.db` and `experiences.db`) that allows the system to recall previous interactions, maintain contextual continuity, and log detailed audit trails for debugging agent cognition.
