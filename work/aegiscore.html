AegisCore

An API firewall that uses embeddings to catch requests that don't look malicious at the surface, but don't belong there either.

The Objective

Traditional Web Application Firewalls (WAFs) rely heavily on regex rules, making them susceptible to bypassed rulesets and zero-day exploits. The goal with AegisCore was to build an intelligent, real-time API firewall acting as a reverse proxy that analyzes the actual semantic meaning of requests to detect complex attacks (SQL injections, XSS, abuse) before they ever reach backend services.

Architecture

AegisCore is structured as a high-throughput proxy layer built on FastAPI and Async I/O. Incoming traffic hits the proxy, is piped through an embedding engine, and undergoes similarity scoring against known attack vectors. Traffic deemed safe is routed to the corresponding backend API. The entire system is packaged in Docker Compose for rapid deployment.

Semantic Analysis & Infrastructure

Instead of matching strings, AegisCore utilizes SentenceTransformers to generate semantic vector embeddings of incoming payload parameters. By measuring the distance between incoming traffic and a known threshold, it detects anomalies mathematically.

To prevent the AI analysis from causing unacceptable latency, a fast Redis cache is positioned in front. Redis also handles the adaptive rate limiting, immediately dropping IPs exhibiting brute-force behavior before invoking the heavier embedding engine.

Engineering Challenges

The primary challenge was balancing latency with security. Running deep learning models in the critical path of an API request can introduce heavy overhead. I mitigated this by writing heavily optimized asynchronous Python, implementing strict caching layers, and tuning the embedding model size to ensure the reverse proxy could handle high concurrent loads without blocking the event loop.
