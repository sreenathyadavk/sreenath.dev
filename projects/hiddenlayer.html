HiddenLayer

An Android app for detecting deepfakes directly on the device, without sending the media to a server.

GitHub Repo
Android UI
HiddenLayer Android Application Interface

The Objective

Identifying AI-generated or manipulated media is a growing necessity. However, relying on cloud APIs for deepfake detection poses a massive privacy risk—users shouldn't have to upload personal photos or live camera feeds to remote servers to verify authenticity. The goal of HiddenLayer was to build a 100% on-device detection system.

Architecture

I built HiddenLayer as a native Android application following Clean Architecture principles (Presentation, Domain, and Data layers). The frontend is built entirely in Jetpack Compose with Material 3. The core engine performs live camera analysis, screen share detection, and batch processing of local media.

On-Device Inference

To avoid cloud dependencies, the ML pipeline runs locally using TensorFlow Lite. I utilized XNNPACK CPU acceleration to optimize the model inference for mobile processors. The engine uses a multi-modal fusion approach, combining CNN inference with artifact and provenance analysis to maintain high detection accuracy.

Engineering Challenges

The hardest engineering constraint was deploying a CNN model to constrained mobile hardware while maintaining real-time frames-per-second (FPS) during live camera analysis. Tuning the TFLite delegates and managing memory in Kotlin natively without causing frame drops or thermal throttling was the key challenge. The result is a fluid, privacy-first edge AI application.
