Nimbus

A self-hosted photo backup and gallery system built with Spring Boot and Android Jetpack Compose.

GitHub Repo
Android Client
Nimbus Jetpack Compose UI

The Objective

Modern gallery apps are heavily reliant on cloud lock-in. I built Nimbus to be a production-grade, self-hosted alternative to Google Photos that prioritizes local media handling, automated backups, and complete data privacy, all running on the user's own hardware.

Architecture

Nimbus is built as a robust client-server architecture. The backend is a robust Java / Spring Boot 3 application responsible for handling large file streams, database transactions, and background media processing. It is containerized with Docker for straightforward self-hosting deployments.

Mobile Client

The frontend is a native Android application built with Kotlin and Jetpack Compose. Inspired by Samsung's OneUI, I designed it to provide fluid navigation, smooth zooming, and a premium responsive feel that rivals native OEM gallery applications.

Engineering Challenges

Reliable media synchronization was the hardest challenge. Handling gigabytes of video and high-resolution photo uploads from a mobile device reliably requires robust state management, background workers that survive app closures, and resumable chunked uploads on the Spring Boot backend to prevent memory exhaustion.
